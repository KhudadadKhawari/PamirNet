# Tenant Admin Assignment

Platform administrators assign PamirNet users to an ISP without selecting tenant-defined roles.

The platform automatically assigns the built-in `Tenant Admin` system role. This role receives all tenant permissions and cannot be edited or deleted by the tenant.

Tenant Admins can then manage their ISP users and create custom roles for their own team members. Platform administrators do not need to understand or select tenant-specific custom roles.

Existing inactive memberships are reactivated and reset to the `Tenant Admin` role when assigned again from Platform Admin.
